01 · Problem

A single shuttle in fixed stop order makes people wait

14 stops from Main Gate to SportX. Visiting them in list order sends the shuttle back and forth across campus, so the loop is long and every stop waits half of it on average.

14
stops with real coordinates
13.37
min loop in file order
6.69
min average wait (baseline)
Average wait = loop time / 2, assuming passengers arrive uniformly and stops are weighted by demand.
02 · Approach

Model the campus as a weighted graph, then solve it in layers

Graph

14 vertices, 22 edges

Edge weight = haversine distance between real stop coordinates at an assumed 20 km/h.

Algorithms

MST · SSSP · APSP · Greedy · DP · TSP

Each one answers a different operational question, and each is cross-checked against a second method.

Cyan = minimum spanning tree (5.8 min).

Going from 2 to 3 shuttles saves 1.88 min. The 4th saves only 0.28. Improvement per extra shuttle first drops below 0.5 min at 4 shuttles, so 3 shuttles (the size of the estimated fleet file) is the sensible operating point.
